# REST API

Base path: `/api`. JSON requests/responses. Dates: `YYYY-MM-DD`; months: `YYYY-MM`.
Except register/login, send `Authorization: Bearer TOKEN`.

| Method | Path | Request / query |
| --- | --- | --- |
| POST | /auth/register | name, email, password (8+ chars) |
| POST | /auth/login | email, password |
| POST | /auth/logout | No body |
| GET | /categories | No query |
| POST | /categories | name, type: INCOME or EXPENSE |
| GET | /transactions | optional from, to, type, categoryId |
| POST | /transactions | categoryId, amount, date, note |
| PUT | /transactions/{id} | categoryId, amount, date, note |
| DELETE | /transactions/{id} | No body |
| GET | /summary | optional from, to |
| GET | /reports/monthly | required month |

Register/login return `token`, `name`, `userId`. The token is a random seven-day session secret; only its hash is saved in SQL.
Summary returns `income`, `expense`, `balance`. Monthly report returns `month`, `summary`, `categories`.
Error JSON contains `message`. Status codes: 400 invalid input, 401 invalid/expired login, 404 missing/other-user entry, 409 duplicate.

Example transaction body:

```json
{"categoryId":1,"amount":250.50,"date":"2026-10-15","note":"Lunch"}
```

IDs are generated by the database; use the IDs from your own `/categories` response.
